# Hand-authored: no Macrobenchmark module exists in this project (generating
# one requires a separate :macrobenchmark Gradle module plus a rooted/AOSP
# emulator image to actually run it, which this environment doesn't have).
# This is deliberately conservative — it lists only the classes that are
# certain to execute on every cold start (Application/Activity entry points
# and the one custom native module registered at boot), not a guess at deep

# dex at install/dexopt time and silently ignores anything it can't match

# build/intermediates/merged_art_profile/release/baseline-prof.txt contains
# ~1300 lines contributed by androidx.appcompat, androidx.work, etc.) — this
# file adds the app's OWN code, which those library profiles don't cover.
